# ListRow

One row of a `List`: an optional leading icon, a title and subtitle, and a trailing control or value.

Padding 12–14px by 16px, title `body-sm`, subtitle `caption` in `ink-muted`. Trailing slot takes a `Switch`, a `Badge`, a value or a chevron. With `href` the whole row is a link and gets a hover fill; don't also put a button in it.
