# TextField

A labelled text input with an optional hint or error below it.

Fill `surface-input`, outline `border-input`, radius `radius-sm`, height `size-control` (44px). Label in `label` style above; hint in `caption` / `ink-muted`. Error text uses `danger` and replaces the hint, and the outline turns `danger`.

Write errors as what to do next: "Use at least 12 characters", not "Invalid password". Always keep the visible label; placeholders are examples, not labels.
