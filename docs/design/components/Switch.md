# Switch

An on/off toggle that takes effect immediately, with no Save button.

Track `surface-control` when off, `accent-strong` when on; white knob. Use it for settings like "Start automatically" or "Remote access". If a change needs confirming or saving, use a checkbox inside a form instead.

Always give it a label, either with `label` or `aria-label`. Put it in the `trailing` slot of a `ListRow` for settings lists.
