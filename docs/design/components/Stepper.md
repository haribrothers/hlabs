# Stepper

Shows where you are in onboarding: "Step N of M" (M = enabled steps, D-041; 6 when every phase has shipped) plus one short bar per step.

Done steps are 70% white, the current step white, later steps 25%. Put it centred above the onboarding card. Steps that can be skipped (remote access, starter apps) still count, so the total never changes mid-flow.
