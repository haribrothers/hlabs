# Menu

Dropdown and right-click menus: file actions, "More" buttons, the app tile menu on Home.

Level-3 glass, radius 14px, `shadow-menu`. Items are 32px tall with an 8px-radius hover in `accent-wash`; shortcuts sit right in `ink-faint`. Group with separators, put the destructive item last in `danger`, and end labels that open a dialog with "…".

The consumer positions the menu, moves focus into it, supports arrow keys and Escape, and returns focus to the trigger.
