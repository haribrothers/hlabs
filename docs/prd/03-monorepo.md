# 03 · Monorepo layout

pnpm workspaces + Turborepo. Package names are scoped `@hlabs/*`. Internal packages are consumed as TypeScript source (`"exports"` pointing at `src/`) during development and built with `tsup` only where a published or bundled artifact is needed.

```
hlabs/
├─ CLAUDE.md                     # rules for Claude Code (read first)
├─ LICENSE                       # AGPL-3.0 (D-047)
├─ package.json                  # root scripts only; no dependencies except tooling
├─ pnpm-workspace.yaml
├─ turbo.json
├─ .github/workflows/            # ci.yml, tray.yml, store.yml, release.yml
├─ apps/
│  ├─ daemon/                    # @hlabs/daemon — hlabsd
│  │  ├─ src/
│  │  │  ├─ main.ts              # boot sequence (02 §2.3)
│  │  │  ├─ server.ts            # Fastify + tRPC adapter + non-tRPC routes
│  │  │  ├─ context.ts           # tRPC context (session, user, tray, setup token)
│  │  │  ├─ routers/             # one file per router in 05-api (thin: validate → service)
│  │  │  ├─ services/            # AppService, AuthService, BackupService, FilesService, NetworkService,
│  │  │  │                       # EngineService, UsageService, UpdateService, NotificationService, JobRunner …
│  │  │  ├─ engine/              # engine detection, dockerode client, compose runner
│  │  │  ├─ caddy/               # config builder + admin API client
│  │  │  ├─ tailscale/           # LocalAPI client, serve config
│  │  │  ├─ backups/             # restic wrapper
│  │  │  ├─ mdns/                # dns-sd / avahi publishers
│  │  │  ├─ events/              # typed event bus
│  │  │  ├─ jobs/                # job queue + persistence
│  │  │  ├─ http/                # /auth/verify, /api/files, /healthz, /mcp
│  │  │  └─ platform/             # macOS vs Linux differences (paths, keychain, mounts, privileges)
│  │  └─ test/                   # integration tests (real SQLite, fake engine)
│  ├─ web/                       # @hlabs/web — dashboard SPA
│  │  ├─ src/routes/             # TanStack Router file routes (one per screen group)
│  │  ├─ src/features/<module>/  # components + hooks per feature file (home, store, apps, files …)
│  │  ├─ src/copy/               # all user-facing strings
│  │  └─ e2e/                    # Playwright specs, named by user story id (us-store-05.spec.ts)
│  ├─ tray/                      # @hlabs/tray — Tauri 2 app
│  │  ├─ src/                    # React UI for the macOS dropdown and dialogs
│  │  └─ src-tauri/              # Rust: tray, bootstrap (LaunchAgent/systemd), keychain, local auth, updater
│  └─ cli/                       # @hlabs/cli — `hlabs` command (status, logs, reset-password, uninstall, setup-url)
├─ packages/
│  ├─ api/                       # @hlabs/api — router types, Zod schemas, event types, error catalogue
│  ├─ db/                        # @hlabs/db — Drizzle schema, migrations, typed settings
│  ├─ app-manifest/              # @hlabs/app-manifest — hlabs-app.yml schema, compose validator, renderer
│  ├─ ui/                        # @hlabs/ui — tokens, Tailwind preset, glass utilities, themed shadcn components,
│  │                             # charts, motion values (source of truth: docs/design/)
│  ├─ icons/                     # @hlabs/icons — Lucide re-exports, tab glyphs, logo, AppLogo, /files (Papirus file icons), assets (already built; ships with these docs)
│  ├─ shared/                    # @hlabs/shared — pure utilities (formatting bytes/durations, ulid, result types)
│  └─ config/                    # @hlabs/config — eslint, prettier, tsconfig bases, vitest preset
├─ store/                        # built-in app catalogue
│  ├─ apps/<appId>/              # hlabs-app.yml, docker-compose.yml, logo.svg, screenshots/
│  ├─ index.json                 # generated by `pnpm store:build`, signed in CI
│  └─ keys/                      # public key of the built-in source
├─ scripts/
│  ├─ install.sh                 # Linux headless installer (also `--uninstall`)
│  ├─ fetch-binaries.ts          # downloads + verifies caddy, restic, compose, node per target
│  └─ release/                   # notarize, package .dmg/.deb/.rpm/.AppImage/.tar.gz
└─ docs/                         # this PRD, design references, decisions
```

## Dependency rules
- `apps/*` may depend on `packages/*`; packages never depend on apps.
- `packages/api` depends only on `zod` and `@hlabs/shared`; it must not import server code. The daemon implements it; web, tray and CLI import its **types**.
- `packages/ui` has no data fetching. Screens live in `apps/web/src/features`.
- `packages/db` is imported only by `apps/daemon`.
- Enforce with `eslint-plugin-boundaries` (or `dependency-cruiser`) in CI.

## Root scripts
| Script | Does |
| --- | --- |
| `pnpm dev` | Turbo: daemon (tsx watch, data dir `./.dev-data`), web (Vite, proxied to the daemon), no Caddy (web talks to daemon directly) |
| `pnpm dev:full` | Also runs Caddy and mDNS so `https://hlabs.local` works locally |
| `pnpm dev:tray` | `tauri dev` against the running dev daemon |
| `pnpm build` | Builds everything |
| `pnpm test` / `pnpm test:e2e` | Vitest / Playwright |
| `pnpm lint` / `pnpm typecheck` | Across the workspace |
| `pnpm db:generate` / `pnpm db:migrate` | drizzle-kit |
| `pnpm store:lint` / `pnpm store:build` | Validate every app in `store/`, generate `index.json` |
| `pnpm ui:tokens` | Generate `packages/ui/src/tokens.css` and the Tailwind theme from `docs/design/tokens.json` |
| `pnpm binaries` | Fetch helper binaries for the current platform |
| `pnpm package:mac` / `pnpm package:linux` | Release artifacts |

## Turborepo pipeline
`build` depends on `^build`; `test` and `typecheck` depend on `^build` of packages only; `lint` has no deps; `package:*` depends on `build` and `binaries`. Cache outputs: `dist/**`, `src-tauri/target/**` (release only).
