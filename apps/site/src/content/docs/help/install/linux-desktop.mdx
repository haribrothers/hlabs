For admins: the person who installs hlabs.

## What you need

- Linux with systemd and a desktop: GNOME, KDE Plasma or another with a system tray.
- Docker Engine, with your account in the `docker` group, or Docker Desktop.
- On GNOME, the AppIndicator extension (Ubuntu includes it) to see hlabs in the top bar. Without it, hlabs says so once and keeps running.

## Install

<Steps>

1. Download the file for your computer from the [download page](/download/), under **Linux desktop**, and install it:

   <Tabs syncKey="distro">
     <TabItem label="Ubuntu and Debian">

       Download `hlabs-<version>-linux-x86_64.deb`, then open it, or run `sudo apt install ./hlabs-<version>-linux-x86_64.deb`.

     </TabItem>
     <TabItem label="Fedora">

       Download `hlabs-<version>-linux-x86_64.rpm`, then run `sudo dnf install ./hlabs-<version>-linux-x86_64.rpm`.

     </TabItem>
     <TabItem label="AppImage">

       Download `hlabs-<version>-linux-x86_64.AppImage`, make it executable (`chmod +x`) and open it. The AppImage needs no administrator, so it uses ports 8443 and 8080 instead of 443 and 80, and it can't connect network drives.

     </TabItem>
   </Tabs>

   On an arm64 computer the files say `aarch64`.

2. Open **hlabs** from your applications. The first time, it sets up its background service and adds itself to the apps that open when you log in. Its icon appears in the top bar, with [its menu](#the-menu):

   <img src={linuxTray.src} alt="The hlabs menu in GNOME's top bar and in KDE Plasma's system tray: hlabs · Running · 11 apps, Open Dashboard, Copy dashboard address, Back up now, Start at login, Pause all apps, Check for updates…, Reset a password…, Quit hlabs." width="900" loading="lazy" />

3. [Setup](../../get-started/set-up/) opens in your browser: your admin account, two-factor login, where your data lives and a few apps to start with.

   <img src={setupWelcome.src} alt="Setup's welcome screen with Get started." width="900" loading="lazy" />

</Steps>

## The menu

Click the hlabs icon in the top bar. The first line says how hlabs is doing, such as **hlabs · Running · 11 apps**; it changes within a few seconds when something does. Then:

- **Open Dashboard** and **Copy dashboard address**.
- **Back up now**.
- **Start at login**: hlabs and its apps start when you log in. Untick it to start them yourself.
- **Pause all apps** (then **Resume apps**).
- **Check for updates…**: the item says what it found. When an update is ready it becomes **Restart to update**.
- **Reset a password…**: for someone who forgot theirs. Your desktop asks for your password first.
- **Quit hlabs**: stops hlabs and every app until you open it again.

When the container engine stops, the menu offers **Start engine**.

## Remove hlabs

Quit hlabs from its menu, then stop its background service and remove the package:

```sh
systemctl --user disable --now hlabsd
sudo apt remove hlabs        # or: sudo dnf remove hlabs, or delete the AppImage
```

Your data stays in `~/hlabs` and `~/.local/share/hlabs`. Delete those folders too if you don't want it any more.

## Install your first app

Open the **App Store** from the Dock, choose an app and **Install**. See [The App Store](../../apps/app-store/).
